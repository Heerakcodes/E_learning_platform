# E-Learning Platform

A Django-based e-learning platform where users can register, log in, browse courses, view course details, and access dashboards. Administrators can manage courses, modules, student records, reports, and certificates.

## Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- JavaScript
